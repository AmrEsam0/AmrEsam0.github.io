Stash

An offline-first encrypted vault for the secrets developers use every day: env files, API keys, tokens, database URLs, SSH keys, logins and 2FA codes. No account, no server, no analytics, no ads.

What it does

Offline first

AES-256-GCM with a key derived from your passphrase via Argon2id, stored in a SQLCipher database. Biometric unlock through Android Keystore or iOS Keychain.

Optional E2E sync

Syncs through a hidden appDataFolder in your own Google Drive. Google only stores ciphertext.

2FA codes

TOTP codes, added by scanning the QR code with the camera.

Autofill

Android AutofillService and an iOS credential provider extension fill logins in other apps.

Stash for Chrome

Fills and saves website logins from the synced vault.

Import

From Google Password Manager, Bitwarden, 1Password, Apple Passwords and KeePassXC. Credential Exchange (FIDO CXF) on Android.
