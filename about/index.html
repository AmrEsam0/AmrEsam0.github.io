How I build

Offline first

The app works with no internet, and sync is a feature on top. Epsilon keeps a café running when the line drops; Stash never needs a server at all.

Security by default

Argon2id and AES-GCM for secrets, Ed25519 for licences and releases, row-level security for tenants. No secrets shipped in plain files.

One owner, end to end

Design, backend, clients, release and ops, from the first schema to the store listing.

Pick the stack by trying it

The Epsilon backend was tried in Go, Kotlin, TypeScript and Rust before settling on Go. Shared Kotlin cores with native UIs on each platform.
